What it checks

Three checks. One honest verdict.

Each file goes through signature verification, a baseline comparison and a set of rules for the tricks malware actually uses.

Authenticode, verified the way Windows does it

WinVerifyTrust checks every embedded signature. Most system files have none of their own, so hashguard looks them up in the signed Windows catalogs too.
